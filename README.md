# VaultX

A minimal Vite + React + Reown/Wagmi app configured for GitHub Pages deployment.

## Quick start

1. Copy `.env.example` to `.env`
2. Fill in your Reown project ID
3. Install dependencies:

```bash
npm install
```

4. Run locally:

```bash
npm run dev
```

5. Build:

```bash
npm run build
```

## Deploy

Push to `main` and GitHub Actions will deploy to GitHub Pages automatically.

Set the repository secret:

- `VITE_REOWN_PROJECT_ID`
